# Package Docs

This docs folder is the package-level manual for `@offline-first-backend-sync/rxdb-sync`.

It is written with a simple rule:

Explain the architecture first, the mechanics second, and the options only when they materially change implementation decisions.

That means the docs are intentionally not written as autogenerated API reference.

They are written in a guide style:

- manual-style prose for concepts and setup
- flat bullets only when the information is genuinely list-shaped
- examples when they reduce ambiguity
- operational notes when they help you avoid real mistakes

If you later publish this package to npm, this folder is the right place to keep the deeper documentation while leaving the package root `README.md` as the short public overview.
